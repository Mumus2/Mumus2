# Política de Privacidade — Clipador

Última atualização: 18/11/2026

O **Clipador** é um aplicativo de uso próprio do canal **Clipou Cortes**
(https://www.youtube.com/@ClipouBR-GTA6). Ele publica cortes de lives no canal e
mostra as estatísticas do canal num painel privado.

## Quais dados o aplicativo acessa

Ao autorizar o Clipador com uma conta Google, o aplicativo pode:

- **Enviar vídeos** ao canal do YouTube autorizado (escopo `youtube.upload`);
- **Editar a descrição, as palavras-chave e o banner** desse canal (escopo `youtube`);
- **Ler as estatísticas e a receita estimada** desse canal (escopos `yt-analytics.readonly`
  e `yt-analytics-monetary.readonly`).

O aplicativo não acessa e-mails, contatos, arquivos, nem dados de nenhuma outra pessoa.

## Como os dados são usados e guardados

- O token de acesso fica salvo **apenas no servidor do próprio dono do canal**.
- As estatísticas são usadas só para exibir o painel privado do canal.
- Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
- O uso dos dados recebidos das APIs do Google segue a
  [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy),
  incluindo os requisitos de uso limitado.

O Clipador usa os Serviços de API do YouTube. Ao usá-lo, valem também os
[Termos de Serviço do YouTube](https://www.youtube.com/t/terms) e a
[Política de Privacidade do Google](https://policies.google.com/privacy).

## Como revogar o acesso

A qualquer momento, em https://myaccount.google.com/permissions → **Clipador** →
**Remover acesso**. Ao revogar, o token deixa de funcionar e pode ser apagado do servidor.

## Exclusão de dados

Ao revogar o acesso, ou a pedido do dono do canal, o token e as estatísticas guardadas no
servidor são apagados em até 30 dias. Veja também os [Termos de Serviço](TERMOS.md).
